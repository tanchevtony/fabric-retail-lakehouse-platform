# Retail Lakehouse Analytics Platform

## Overview

This project demonstrates a complete Data Engineering solution built using Microsoft Fabric.

The solution implements a Medallion Architecture (Bronze, Silver, Gold) to ingest, transform, and serve retail analytics data.

## Business Problem

Contoso Retail Group receives transactional data from multiple operational systems.

The company requires:

- Daily sales reporting
- Product performance tracking
- Customer analytics
- Return analysis

## Solution

Microsoft Fabric is used to:

- Ingest retail datasets
- Store data in OneLake
- Transform data with PySpark
- Build Delta Lake tables
- Create analytical datasets
- Optimize query performance
